Problem & Innovation

The Problem vs. The CineVista 3D Solution

⚠ Traditional Booking Portals

  • Flat 2D Grid Disconnect: Patrons cannot gauge sightlines, viewing angles, screen distance, or elevation until they enter the hall.
  • Scattered Steps: Trailers, showtimes, multiplex schedules, and seat maps are disjointed across separate pages.
  • Concurrency Failures: Weak locking causes simultaneous transaction failures during blockbuster booking rushes.
  • Static Seat Charts: Bland spreadsheet-like experience lacking cinematic immersion.

★ The CineVista 3D Solution

  • Immersive 3D Auditorium: Real-time WebGL space with accurate tier elevations and Christie 4K laser curved screen.
  • 'Feel The View' First-Person POV: Clicking any seat glides the camera directly to that exact eye-view perspective.
  • Live Trailer on Canvas: The film's official trailer streams directly on the virtual 3D cinema screen as an interactive video texture.
  • Guaranteed Zero Double-Bookings: PostgreSQL row-level locks ensure atomic multi-seat transactions.
System Design

Full-Stack Technology Stack & Architecture

FRONTEND LAYER

Next.js 14 + React 18

  • • Three.js & React Three Fiber (R3F) WebGL rendering
  • • Zustand for atomic reactive booking state
  • • Tailwind CSS for responsive styling
  • • Full Dark/Light Theme with localStorage
  • • 6-Row 3D moving poster preloader wall
BACKEND MICROSERVICES

Plain Java (JDK HttpServer)

  • • Zero-overhead, low-latency REST endpoints
  • • Custom JSON marshalling & CORS handling
  • • Dedicated atomic BookingHandler
  • • Strict input validation regex on seat labels
  • • Tested with 50 concurrent seat threads
DATABASE ENGINE

PostgreSQL + JDBC Pool

  • • Custom connection pool (25 connections)
  • • Row-level lock (SELECT ... FOR UPDATE)
  • • Enforced compound key: (show_id, seat_label)
  • • 32 master Indian cinema catalog titles
  • • 6,400+ scheduled screenings across 9 venues
